# x402 paid services

Reference for agents calling the paid endpoints. Every service follows the same flow; only the request body, the price and the limits differ. The routes are disabled unless `X402_ENABLED=true`, and settle in Algorand USDC (see the [README](../README.md#algorand-x402-machine-payable-quantum-services)).

## Flow

1. `POST` the request body to the service route with no payment. The response is `402 Payment Required`. The `PAYMENT-REQUIRED` header holds a base64 JSON document with the price (`accepts[0].amount`, in USDC micro-units), the receiver and an example request in `extensions.bazaar`.
2. Pay on-chain and send the same `POST` again with the signed payment in the `PAYMENT-SIGNATURE` header. The response carries a `job_id`.
3. Poll `GET <route>/{job_id}` until `status` is `completed` or `failed`. Polling is free and needs no payment header.

An unpaid or invalid call is rejected with `402` before the backend is contacted, so it creates no job. A job can only be read back through its own `job_id`, which is generated by the server, and paid jobs are never listed.

## Services

| Service | Route | Default price | Env variable |
|---|---|---|---|
| Quantum circuit | `/api/x402/quantum/runs` | $0.01 | `X402_QUANTUM_RUN_PRICE` |
| QAE options | `/api/x402/options/runs` | $0.01 | `X402_QUANTUM_RUN_PRICE` |
| Risk | `/api/x402/risk/runs` | $0.05 | `X402_RISK_RUN_PRICE` |
| Finance | `/api/x402/finance/runs` | $0.05 | `X402_FINANCE_RUN_PRICE` |
| Pharma | `/api/x402/pharma/runs` | $0.25 | `X402_PHARMA_RUN_PRICE` |

Prices are flat per call. Dynamic pricing is not part of this change.

## Risk

`POST /api/x402/risk/runs`, JSON body:

| Field | Type | Notes |
|---|---|---|
| `risk_model` | `"equity"` or `"credit"` | Default `equity` |
| `holdings` | list | Equity mode. Each item has `ticker` and `weight`. At most 20. Oracle-priced holdings (`chainlink_price`) are rejected with 422. |
| `assets` | list | Credit mode. Each item has `principal`, `default_probability` (0 to 1) and `recovery_rate` (0 to 1). At most 15. |
| `lookback_days` | integer | 60 to 2520, default 504 |

```json
{
  "risk_model": "equity",
  "holdings": [
    { "ticker": "AAPL", "weight": 0.5 },
    { "ticker": "MSFT", "weight": 0.5 }
  ],
  "lookback_days": 504
}
```

## Finance

`POST /api/x402/finance/runs`, JSON body. It optimises a portfolio of tokenized stocks and never trades.

| Field | Type | Notes |
|---|---|---|
| `symbols` | list of strings | 2 to 20 of `AAPL`, `MSFT`, `NVDA`, `GOOGL`, `AMZN`, `META`, `TSLA`, `SPY`, `QQQ` |
| `start_date`, `end_date` | `YYYY-MM-DD` | Price history range |
| `budget` | integer | Optional, at least 1 |
| `risk_aversion` | number | 0 to 10, default 0.5 |

```json
{
  "symbols": ["AAPL", "MSFT", "NVDA"],
  "start_date": "2025-01-01",
  "end_date": "2025-06-30",
  "risk_aversion": 0.5
}
```

Unknown fields are rejected.

## Pharma

`POST /api/x402/pharma/runs`, JSON body:

| Field | Type | Notes |
|---|---|---|
| `mode` | `"optimization"` or `"discovery"` | Required |
| `target_pdb_id` | string | Protein Data Bank id, 3 to 10 characters. Required. |
| `initial_ligand_smiles` | string | Optional, at most 500 characters |
| `max_iterations` | integer | 1 to 5 over x402 |
| `candidate_count` | integer | 10 to 100 over x402 |

```json
{
  "mode": "discovery",
  "target_pdb_id": "1HSG",
  "max_iterations": 3,
  "candidate_count": 50
}
```

Pharma jobs are stored in MongoDB under the x402 owner. A job that was still running when the backend restarted is reported as `failed` with the error `interrupted by a backend restart`, so a paid caller can see it ended and submit again.

## Responses

Submitting returns a `job_id` and a `status` of `queued`. Polling returns the job with its `status`, its `result` once `completed`, or an `error` when `failed`. A request that exceeds a limit above returns `422` and creates no job.
